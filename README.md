# ai-podcast
A podcast streaming application designed entirely for personal use

### Podcast app
- Open the purple "Podcasts" app on your iPhone.
- Select "Library" from the tabs at the bottom.
- Tap the "..." button in the top-right corner of the screen and select "Add Show by URL."
- Enter the URL mentioned above and tap "Follow." https://eisuke0626.github.io/ai-podcast/feed.xml
